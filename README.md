# 冷蔵庫の残り物から今日の三択

冷蔵庫の在庫管理を中心に、残っている食材から今日作れる料理を3案に絞って提案するスマートフォン向けプロトタイプです。

## 試せること

- 1人・2人・4人分の切り替え
- 「買い足しなし」「使い切り」「時短」による優先条件の変更
- レシピごとの「最低限必要」と「あるとより良い」食材の区別
- 手元にある追加食材の選択
- 食材の追加、編集、削除、残量の増減、保存場所による絞り込み
- 一般的な食材12種類のイラスト表示（未対応食材は頭文字で表示）
- トップ画面の冷蔵庫イラストから在庫を見渡し、独立した在庫管理画面へ移動
- 「まだある」「先に使う」「使い切った」のワンタップ操作
- 使い切った食材の復元
- 調理後の在庫更新
- ブラウザ内への在庫データ保存

現在は少数のサンプル料理を使う検証版です。賞味期限、アカウント、複数端末間の同期にはまだ対応していません。
