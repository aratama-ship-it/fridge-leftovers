# 冷蔵庫の残り物から今日の三択

冷蔵庫の在庫管理を中心に、残っている食材から今日作れる料理を3案に絞って提案するスマートフォン向けプロトタイプです。

## 試せること

- 作る直前の確認画面で、1〜4人分を選び、実際に使う材料と量を確認
- 「あるとより良い」食材は、調理前の確認画面で使う・使わないを選択
- レシピ画面の最上部にある食材イラストをタップし、冷蔵庫型の一覧から「今日使いたい食材」を再選択
- レシピごとの「最低限必要」と「あるとより良い」食材の区別
- 主食・肉・魚・卵・豆腐・野菜・麺・パン・汁物を含む定番レシピ77件から、今ある食材に近い3件を提案
- 各レシピに、1人分のkcalとPFCバランスの概算を小さく表示
- 手元にある追加食材の選択
- 食材の追加、編集、削除、残量の増減、保存場所による絞り込み
- 残量と買う数量は、直接入力・スライダー・プラス／マイナスボタンの3通りで変更
- 食材追加は「野菜・魚介・肉」などの分類からイラストをたどって選択し、最近追加した食材を各分類の先頭に表示（文字入力は一覧にない食材の補助）
- 食材追加画面の上部から、レシート撮影・画像選択による一括追加へ直接移動
- 一般的な食材108種類のイラスト表示（未対応食材は頭文字で表示）
- レシート認識と文字入力は107種類に対応。イラストが無い食材は冷蔵庫では頭文字で表示され、イラストの一覧からは選べません
- トップ画面の冷蔵庫イラストから在庫を見渡し、独立した在庫管理画面へ移動
- 常温保存の食材は、冷蔵庫の下にある二段のパントリー棚で確認・追加
- トップ画面では具体的な数量を出さず、食材イラストと「少なめ」で状態を確認
- 冷蔵庫・パントリーの食材を子どものイラストへドラッグして、食べて使い切った状態に更新
- 冷蔵庫の直下から「買うもの」「今日何作る？」「食材を追加」へ移動
- 料理提案は最初に3件を表示し、「あと3つ見る」で3件ずつ候補を追加
- 各料理の簡単な3手順を、必要なときだけ開いて確認
- 調理で減った食材を履歴へ記録し、最下部の「履歴」から取り消して在庫へ戻す
- レシート写真を端末内OCRで読み取り、候補を確認して一括追加
- 「まだある」「先に使う」「使い切った」のワンタップ操作
- 使い切った食材の復元
- 調理後の在庫更新
- 次の買い物を売り場カテゴリと食材イラストから選択し、同じイラストの再タップで解除（文字入力は一覧にないものの補助）
- 現在の在庫とレシピの不足食材から「買うと料理につながるもの」を推薦
- ブラウザ内への在庫・買い物データ保存

レシート認識には、アプリ内へ同梱したTesseract.jsと日本語学習データを使用します。写真を外部OCR APIへ送信せず、解析後の写真も保存しません。第三者ライセンスは[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)を参照してください。

現在は77件の定番料理を使う検証版です。栄養値は食品ごとの一般的な参考値と基本調味料の仮定から丸めた目安であり、商品表示や医療・栄養指導の代わりにはなりません。賞味期限、アカウント、複数端末間の同期にはまだ対応していません。

## 開発環境メモ

作業ツリーは iCloud Drive 上にありますが、`.git` は iCloud 同期による破損を避けるため `~/git-repos/fridge-leftovers` へ退避しています（`git init --separate-git-dir`）。リポジトリ直下の `.git` は、その場所を指す48バイトのテキストファイルです。

- 2026-07-25 に実施。それまでは iCloud が `.git` の競合コピーを14個作り、`refs/remotes/origin/main 2` のような不正な ref 名で `git fsck` がエラーを出す状態だった
- この構成は、この Mac 1台での作業を前提にしている。別の端末では `.git` の参照先が存在しないため git 操作ができない
