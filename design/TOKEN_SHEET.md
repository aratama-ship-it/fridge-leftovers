## 0. コンセプト1行

**紙の上の冷蔵庫。読ませる文字は十分に大きく、装飾の記号は小さく静かに。**

食材の水彩イラストが固有性を持っている。文字とUI記号はそれを邪魔せず、
「見た瞬間に中身を思い出せる」ための土台に徹する。

## 2. タイポグラフィ（今回の中心）

### 書体

- 和文・欧文とも `-apple-system, BlinkMacSystemFont, "Hiragino Sans", "Yu Gothic UI", sans-serif` の1系統のみ。
  Webフォントは読み込まない（初回8.1MBのうち7.4MBが食材イラスト。文字にこれ以上足さない）。
- 例外1: 料理名だけ明朝（`ui-serif`）。「読ませる」対象で、レシピカードの罫線紙と合う。
- 例外2: 数字のバッジは `sans-serif` 直指定（等幅寄りの見え方を優先）。
- A_design §3「使用書体は1〜2種類まで」に適合。

### スケール（基準 16px・比率およそ1.2）

| トークン | rem | px | 行送り | 用途 | 移行元（旧px） |
|---|---|---|---|---|---|
| `--fs-micro` | 0.6875 | **11** | 1 | **非テキストの微小ラベルだけ**（バッジの数字・版の刻印・装飾） | 8.16–10.4 の一部 |
| `--fs-caption` | 0.75 | **12** | 1.5 | 注記・eyebrow・補足・状態タグ ← **読ませる文字の下限** | 8.16–11.84 |
| `--fs-sub` | 0.875 | **14** | 1.55 | 補助情報・ナビラベル・行操作・小ボタン | 12.00–13.60 |
| `--fs-body` | 1 | **16** | 1.6 | 本文・カードの主情報・**フォーム部品** | 13.76–16.32 |
| `--fs-lead` | 1.125 | **18** | 1.45 | カード見出し・節見出し（h3） | 16.80–18.88 |
| `--fs-title` | 1.375 | **22** | 1.35 | 画面見出し（h2）・注目レシピ名・人数の数字 | 19.20–21.60 |
| `--fs-display` | 1.625 | **26** | 1.3 | タブレット（700px以上）の画面見出し・読み上げ用h1 | 24.80 |

- **ジャンプ率** `--fs-title` ÷ `--fs-body` = 1.375。A_design §3 は「見出しは本文の2倍程度」だが、
  それは紙面の話。1画面に見出しが1つしかないスマホUIでは2倍は過剰なので、
  現状（21.6÷16=1.35）をほぼ維持して**下を上げることで差を作る**方針を採る。
- **行長**: `.app-shell` の最大幅540px、本文16pxで全角およそ30字。A_design §3 の「30〜50字」に収まる。
- **行送り**: A_design §3「文字サイズの50〜100%＝行送り1.5〜2.0倍」。上表はその下限側。
  情報密度の高いアプリなので広げすぎない。

### 下限の例外（`--fs-micro` を使ってよい場所）

**読まなくても操作できるもの**に限る。ここ以外で11pxを使わない。

| 場所 | 中身 | 理由 |
|---|---|---|
| `.app-version` | `v0.18.0` | 版の刻印。普段は読まない。不具合報告のときだけ拾う |
| `.nav-icon-with-count small` | 買い物の件数 | 17px の丸バッジの中。12pxでは収まらない |
| `.food-expiry-badge` | 期限の印 | 56px の食材イラストの上に載る印 |
| `.food-child-bubble` | 「ぱくっ」 | 装飾 |
| `.shopping-food-button.is-added::after` / `.priority-food-option.is-selected::after` | ✓ | 選択済みの印 |
| `.shopping-food-button strong` | 売り場グリッドの品名 | 3〜4列の格子。12pxにすると名前が省略される（→ B-3のグリッド見直しで解消する） |
| `.shopping-food-button small` | 売り場グリッドの数量 | 同上 |

### フォーム部品の下限（iOS対策・変更不可）

`input` / `select` / `textarea` は **16px（`--fs-body`）を下回らせない**。
iOS Safari は 16px 未満の入力欄にフォーカスすると**ページを勝手に拡大する**。
PWAとして全画面で使うため、拡大されると戻せない。

## 3. 記号・アイコンの大きさ（テキストとは別の軸）

文字サイズのトークンで記号の大きさを決めない。同じ「18px」でも、読む文字と押す記号では意味が違う。

| トークン | px | 用途 |
|---|---|---|
| `--icon-sm` | 18 | 行内の矢印・シェブロン・小さな＋− |
| `--icon-md` | 22 | 下部ナビ・数量の＋−・設定の歯車 |
| `--icon-lg` | 26 | 閉じる×・棚の段数の＋− |
| `--icon-xl` | 32 | 空状態の大きな印 |

- タップ領域は大きさと別。**44×44px 以上**を保つ（A_design §5「タッチ対象は指で選択できる大きさ」）。

### アイコンの描き方（B-2bで導入・インラインSVG）

文字記号（▥ ▤ ⌁ ✓ ↶）は端末のフォントで形が変わるうえ、▥ と ▤ は並べると見分けられなかった。
インラインSVGへ置き換え、次の規則で描く。

| 項目 | 値 |
|---|---|
| viewBox | `0 0 24 24` |
| 塗り | `fill: none`（線画のみ） |
| 線 | `stroke: currentColor` — 現在地の色（`.is-active`）へそのまま追従する |
| 太さ | `1.7`（空状態の大きい印だけ `1.6`） |
| 端・角 | `round` |
| 大きさ | `--icon-*` のみで決める。`font-size` では決めない |

| 画面 | 図案 |
|---|---|
| 冷蔵庫 | 縦長の角丸枠＋横の仕切り＋左に短い取っ手2本 |
| 在庫 | 点＋横線の3行（一覧） |
| レシピ | 鍋（幅広の蓋線・左右に出る取っ手・湯気2本） |
| 買い物 | かご（半円の提げ手・中に縦のすじ2本） |
| 履歴 | 時計＋反時計回りの矢印 |

- **レシピと買い物は最初どちらも「幅広の横線＋台形」で22pxだと見分けられなかった。**
  鍋に左右へ出る取っ手と湯気、かごに半円の提げ手を足して輪郭を分けた。
  22pxと88pxの両方で並べて判別できることを確認している。
- 見出し脇にあった装飾記号（買い物の「／」・履歴の「↶」）は削除した。
  端末によって欠けた図形に見えるうえ、見出しの文字とナビのアイコンで足りている。
- 履歴の空状態は「♨」をやめ、鍋のアイコン（`--icon-xl`）にした。

## 4. 余白・レイアウト（今回は現状維持・記録のみ）

- コンテナ最大幅: 540px（スマホ）／900px（700px以上）

## 5. 形状

- 角丸: 3〜5px（小） / 7〜13px（カード・ダイアログ）
- 影: `0 -5px 16px var(--shadow)`（ナビ）／`0 0 34px rgb(34 39 34 / 12%)`（タブレットのシェル）

## 6. モーション

- `prefers-reduced-motion: reduce` に対応済み（起動スピナーを止める）
