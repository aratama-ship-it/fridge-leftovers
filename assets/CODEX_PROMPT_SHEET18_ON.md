### 必ず通してほしい確認（今回追加）

**1. シートを作ったら、背景抜けを数えて確かめる**

```bash
node scripts/check-atlas-alpha.mjs 18
```

12マスぶんの「不透明率」と「緑の割合」が出る。判定は次のとおり。

- **不透明率が60%を超えたマスは、背景が抜けていない**（★付きで出る）。
  正常なマスは9〜30%に収まる。前回失敗した4マスはここで確実に引っかかる
- 緑の割合が5%を超えると「?」が付く。**被写体そのものが緑なら問題ない**
  （既存だとパセリが8.7%で正常）。緑でないものに付いたら抜けていない

これが `背景抜け OK` になるまで、シートを次へ進めないでほしい。

**2. 抜けていなかったら、抜き直してシートを作り直す**

```bash
node scripts/key-green.mjs assets/atlas-src/18/xxx.png
```

緑らしさ `g - max(r, b)` で判定して背景を透過にし、境界の緑かぶりを抜く。
**対象ファイルを明示的に渡す作りにしてある**。バジル・絹さや・小ねぎ・ライムの
ように被写体が緑の素材へ当てると中身まで消えるので、フォルダ一括処理はできない。
抜き直したら `build-atlas.mjs` でそのシートを作り直し、1をもう一度通す。
