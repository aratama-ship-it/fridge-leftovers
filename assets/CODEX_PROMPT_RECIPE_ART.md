# Codex へ送るプロンプト（料理の完成イラスト・77品）

食材イラスト324点と同じ流れで、**77レシピの「完成した料理」の絵**を作ってもらう。
候補カードにいまは文字と食材イラストしか無く、方針書の未実装の筆頭がこれ。

---

## 貼る本文

冷蔵庫アプリの、料理の完成イラストを描いてほしい。食材イラスト27枚を作って
もらった、あのアプリ。今回は食材ではなく**完成した料理**が77品。

作業場所:
`/Users/arata/Library/Mobile Documents/com~apple~CloudDocs/claude code files/app-dev/fridge-leftovers`

### 何に使うか

レシピ画面の候補カードに載せる。**「今日のおすすめ」1件を大きく、ほかの候補を
控えめに**見せる画面で、料理の絵が候補選びの主役になる。表示サイズは
おおよそ72〜120px。

### 描き方

- **食材イラストと同じ水彩の描き味。** `assets/ingredient-atlas-19.png` などを
  開いて、質感と線をそろえてほしい
- **器に盛った完成品**を描く。湯気は描いてよい（温かい料理のみ）
- 各料理の器は下の表の「器・見せ方」に従う。**同じ器ばかりにしない**
  （食材イラストのときの器の使い分けが良かった。同じ調子で）
- 箸・スプーン・手・テーブル・ランチョンマット・文字は描かない
- 背景は完全に透過。地面に落ちる影は描かない。輪郭を黒線で囲まない
- 1マス1料理

### 用紙（食材イラストと同じ）

- **1254 × 940 px**、PNG、横4列 × 縦3行の12マス
- 素材は `assets/atlas-src/r01/` のようにシートごとのフォルダへ、**idの名前**で保存
- シートを組むときは build-atlas を使う。**出力名が食材と違う**ので注意:

```bash
node scripts/build-atlas.mjs 01 miso-stir-fry egg-bowl cabbage-pancake mushroom-soup home-curry nikujaga hamburger-steak salmon-meuniere napolitan tofu-miso-soup chicken-cabbage-steam tomato-egg-stir-fry --source-dir assets/atlas-src/r01 --output assets/recipe-atlas-01.png
```

- 最後のシート r07 は5品しか無い。**残りは `_` で空のまま**にする:

```bash
node scripts/build-atlas.mjs 07 cheese-toast pizza-toast tuna-toast french-toast egg-sandwich _ _ _ _ _ _ _ --source-dir assets/atlas-src/r07 --output assets/recipe-atlas-07.png
```

### 1枚ごとに通す確認

```bash
node scripts/check-atlas-alpha.mjs r01
```

`背景抜け OK` になるまで次へ進まない。抜けていなければ
`node scripts/key-green.mjs --auto assets/atlas-src/r01/xxx.png` で抜き直して
シートを作り直す（緑の料理＝ほうれん草のおひたし等へ --auto を当てるときは、
四隅がそろっていなければ何もしない作りなので安全）。

### 気をつけてほしい描き分け

- **炒め物どうし**（味噌炒め・野菜炒め・肉野菜炒めなど）は、主役の食材の色が
  はっきり見えるようにする。全部が茶色い山にならないこと
- **丼もの**は上の具で見分ける（卵とじ・そぼろ・照り焼きなど）
- **スープ・汁もの**は具が水面から見えるように
- **同じ料理名の和風・洋風**（例：うどんとパスタ）は器でも分ける
- 迷ったら「日本の家庭の食卓に出てくる姿」を描く。店の盛り付けにしない

### 72pxで読めるかを必ず確かめる

各料理を72pxまで縮めて、**何の料理か（少なくとも麺か丼か汁か炒め物か）が
分かる**ことを確認してほしい。細かい具の描き込みより、シルエットと色の対比。

### やらないこと

- `app.js`・`styles.css`・`scripts/` は触らない。アプリへの組み込みはこちら
- **commit と push はしない**
- 描けない場合は仮の絵で埋めず、その旨を報告する

### 報告してほしいこと

- 完成したシート番号（77品すべてでなくてよい。**途中まででも受け取れる**。
  次にどのシートから始めればよいかを書く）
- `check-atlas-alpha.mjs` の結果（シートごと）
- 72pxで見分けにくかった料理があれば、そのid
- **前回の宿題**：バター・マーガリン・卵豆腐の描き直し
  （`assets/CODEX_PROMPT_SHEET20_ON.md` の末尾）がまだなら、今回の合間に
  やってもらえると助かる
