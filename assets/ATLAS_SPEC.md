# 食材イラスト・アトラスの仕様

食材イラストは1枚の画像に12個をまとめた「アトラス」で管理し、CSSの背景位置で1つずつ切り出している。

## ★寸法の重要な訂正（2026-07-25）

**既存4枚は 1254 × 1254 px だが、この寸法は誤り。** 正しくは **1254 × 940 px**（横 : 縦 = 4 : 3）。

理由。表示側は `background-size: 440% 330%` で、正方形の要素に対して画像を「横4.4倍・縦3.3倍」に描く。
つまり画像を**横4列・縦3行の正方形マス**として扱う。マスが正方形になるシート寸法は
`高さ = 幅 × 3.3 / 4.4 = 幅 × 0.75` なので、幅1254なら高さは940。

シートが 1254 × 1254 だとマスが 313.5 × 418 の縦長になり、それを正方形のマスへ描くため
**被写体は縦へ約33%潰れて表示される**。隣のマスの端も映り込む。

実測で確認済み（要素52×52、`background-size: 440% 330%`）。
正円を描いたテスト用アトラスで比較すると、1254×1254では横長の楕円になり、1254×940では正円になる。

- **新しいシートは必ず 1254 × 940 px で作る**
- 既存4枚（base / everyday / recipe / expanded）は潰れたまま。修正には12個を切り出して
  940px の高さへ再配置する作業が必要で、これは別タスクとして残している

## 画像の仕様（新規シート）

- **サイズ**：**1254 × 940 px**
- **形式**：PNG、**背景は透過**
- **配置**：横4列 × 縦3行の12マス。1マスは **313.5 × 313.3 px（ほぼ正方形）**
- **各マスの中心**に被写体を置く。被写体はマス幅の 60〜75% 程度に収め、端に寄せない
- 隣のマスへはみ出さない（表示時に約10%外側までクロップされるため、余白を確保する）

マスの中心座標（px）。

## 絵柄

既存4枚は次の描き方で統一されている（`ingredient-atlas.png` と `ingredient-atlas-expanded.png` を開いて確認した）。

- 透過背景に描いた**水彩・不透明水彩ふうの食材イラスト**。図鑑の挿絵に近い
- 写実寄りだが写真ではない。輪郭を黒線で囲まず、色と陰影で形を作る
- 被写体の外側に**ごく細い明るいクリーム色の縁**があり、背景から浮いて見える（棚の色に乗せても輪郭が読める）
- 光は左上からの柔らかい環境光。地面に落ちる影は描かない
- 彩度は自然でやや落ち着いた色。蛍光色は使わない
- 角度は素直な真横〜斜め45度。極端なパースは付けない
- 単品、または少量をまとめた状態（もやし・にらのように束ねる、豚こまのように数枚重ねる）
- 皿や小物は描かない。ただし器がないと成立しないものだけ器を描く
  （ごはんは青い縞の茶碗、ツナは白い小鉢）
- 文字・ラベル・パッケージは描かない

## 画像ができたら行う作業

1. `assets/ingredient-atlas-<名前>.png` として保存する
2. `styles.css` の `.ingredient-illustration-s05` 〜 `-s13` を使う（用意済み）
3. `app.js` の `INGREDIENT_ILLUSTRATIONS` へ `id: [列, 行, "<名前>"]` を追記する
4. `app.js` の `ILLUSTRATED_INGREDIENT_CATEGORIES` の `items` へ id を足す（イラストの一覧に出す）
5. `app.js` の `RECEIPT_RULES` / `ALIASES` / `NUTRITION_REFERENCES` を整える（新規食材の場合）
6. `node scripts/cache-version.mjs` を実行し、`styles.css` 内の画像 `?v=` も更新する
7. `node scripts/check-initial-units.mjs` が通ることを確認する

## 登録済みなのにイラストが無い食材
