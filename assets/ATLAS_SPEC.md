# 食材イラスト・アトラスの仕様

食材イラストは1枚の画像に12個をまとめた「アトラス」で管理し、CSSの背景位置で1つずつ切り出している。
新しい食材のイラストを足すときは、この仕様に合わせる。

## 現状

| アトラス | ファイル | 収録 |
|---|---|---|
| base | `ingredient-atlas.png` | 12/12（満杯） |
| everyday | `ingredient-atlas-everyday.png` | 12/12（満杯） |
| recipe | `ingredient-atlas-recipe.png` | 12/12（満杯） |
| expanded | `ingredient-atlas-expanded.png` | 12/12（満杯） |
| extra | `ingredient-atlas-extra.png` | **未作成** |

4枚とも満杯のため、食材を足すには5枚目（extra）が必要。CSSの受け口は用意済み。

## 画像の仕様

- **サイズ**：1254 × 1254 px（既存4枚と同じ）
- **形式**：PNG、**背景は透過**
- **配置**：横4列 × 縦3行の12マス。1マスは 313.5 × 418 px
- **各マスの中心**に被写体を置く。マスの端まで描かず、余白を残す
- **被写体の大きさ・向き・光の当たり方・影の付け方を既存4枚とそろえる**（既存アトラスを開いて隣に並べて確認する）

マスの中心座標（px）は次のとおり。

| | 列0 | 列1 | 列2 | 列3 |
|---|---|---|---|---|
| **行0** | (157, 209) | (470, 209) | (784, 209) | (1097, 209) |
| **行1** | (157, 627) | (470, 627) | (784, 627) | (1097, 627) |
| **行2** | (157, 1045) | (470, 1045) | (784, 1045) | (1097, 1045) |

## 絵柄

既存4枚は、透過背景に描いた**緻密な食材イラスト**で統一されている。

- 写実寄りだが写真ではない、図鑑の挿絵に近い塗り
- 光沢と陰影をしっかり描き込み、素材の質感（麺のツヤ、魚の鱗、野菜の繊維）が分かる
- 輪郭線は引かず、色と陰影で形を作る
- 背景・皿・小物は描かない（ツナ缶の中身のように器が必要なものだけ器を描く）
- 単品、または少量をまとめた状態（もやし・にらのように束ねる）

## extra へ入れる予定（5件）

| マス | 食材 | id | 描くもの |
|---|---|---|---|
| 行0・列0 | アスパラガス | `asparagus` | 数本を束ねた状態 |
| 行0・列1 | ベーコン | `bacon` | スライス数枚を少し重ねた状態 |
| 行0・列2 | バターロール | `butter-roll` | 2〜3個 |
| 行0・列3 | 鶏もも肉 | `chicken-thigh` | 皮つきの生肉1枚 |
| 行1・列0 | かつお節 | `bonito` | 削り節をひとつまみ／小袋 |

残り7マスは今後の追加用に空けておく。

## 画像ができたら行う3つの作業

1. `assets/ingredient-atlas-extra.png` として保存する
2. `app.js` の `INGREDIENT_ILLUSTRATIONS` へ追記する（`[列, 行, "extra"]`）

   ```js
   asparagus: [0, 0, "extra"],
   bacon: [1, 0, "extra"],
   "butter-roll": [2, 0, "extra"],
   "chicken-thigh": [3, 0, "extra"],
   bonito: [0, 1, "extra"],
   ```

3. `app.js` の `ILLUSTRATED_INGREDIENT_CATEGORIES` の `items` へ id を足し、イラストの一覧から選べるようにする
   （アスパラガスは野菜・きのこ、ベーコンと鶏もも肉は肉、バターロールは主食・麺、かつお節は乾物・その他）

そのあと `node scripts/cache-version.mjs` を実行し、`styles.css` 内の
`ingredient-atlas-extra.png?v=` の日付も更新してから公開する。

## 登録済みなのにイラストが無い食材の確認方法

```
node -e '...' # RECEIPT_RULES と INGREDIENT_ILLUSTRATIONS を突き合わせる
```

イラストが無い食材は、冷蔵庫では**頭文字**で表示され、イラストの一覧には出ない。
