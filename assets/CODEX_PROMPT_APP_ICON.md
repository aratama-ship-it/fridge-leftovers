# Codex へ送るプロンプト（アプリのアイコン）

いまのアイコンは Claude が `scripts/build-icons.mjs` の中で手続き的に描いた平たい
ベクター。**アプリ内の食材イラストが水彩なので、アイコンだけ描き味が違って浮いている。**
同じ水彩の描き味で描き直してもらう。

**渡す形は「前景の透過PNG 1枚 + 背景色の指定」**にしてある。こちらで各サイズと
Android用の maskable を組み立てるため（下の「なぜこの形で渡すのか」を参照）。

### いまのアイコンと、直したいこと

`assets/icons/icon-512.png` を開いてほしい。深い緑の地に、クリーム色の冷蔵庫が
描いてある。中に淡い青の冷凍室と、棚2本、中身の粒が3つ。

**これは平たいベクターで、アプリの中身と描き味が違う。** 食材イラスト（例えば
`assets/ingredient-atlas-19.png` や `24.png`）は水彩の質感があるのに、アイコンだけ
のっぺりしている。ホーム画面で最初に目に入るものなので、ここが一番アプリらしく
あってほしい。**同じ水彩の描き味で描き直してほしい。**

### 何を描くか

**「中身が見えている冷蔵庫」**を、食材イラストと同じ水彩で。

- 扉が開いていて、棚に食材が乗っている。何が乗っているかまでは読めなくてよい
- このアプリは「帰り道に冷蔵庫の中身を思い出す」ためのもの。**中身が見えていること**が
  絵の主題で、冷蔵庫という箱そのものではない
- アプリ名は「冷蔵庫の現在地」、見出しは「台所の在庫帳」。家庭の台所の道具という
  たたずまいで、家電量販店のカタログのような冷たさは避けたい

**文字・数字・ロゴは入れない。**

### 配色

アプリ本体の色に合わせる（`styles.css` の `:root` と `.fridge-*` にある）。

| 用途 | 色 |
|---|---|
| 紙・本体 | `#f3f0e6`（クリーム） |
| 葉色（地に使っている） | `#2f644b` → `#1d4331`（上から下へ） |
| 冷凍室の淡い青 | `#c7e2ed` |
| 庫内 | `#e7eee8` |
| 棚 | `#96a99c` |
| 差し色（中身の赤） | `#a8492d` |
| 差し色（中身の緑・黄） | `#4c7a52` / `#e8c25f` |

地の色は変えてよいが、**変えるなら理由と色を報告に書いてほしい**。アプリの画面と
つながって見えることが条件。

### 提出物（★ここが普段と違う）

**2つだけ渡してほしい。**

1. `assets/icon-src/foreground-1024.png`
   - **1024 × 1024 px、背景は完全に透過**
   - 絵柄（冷蔵庫）だけを描く。地の色は塗らない
   - **絵柄は中央の直径80%の円（半径410px）の内側に収める。** はみ出すと
     Androidで角が切り落とされる
2. `assets/icon-src/background.txt`
   - 地の色を1行か2行で書く。1行なら単色、2行なら上から下へのグラデーション
   - 例（いまの色）:
     ```
     #2f644b
     #1d4331
     ```

**各サイズ（512 / 192 / 180 / 32）とAndroid用の maskable は、こちらで組み立てる。**
`scripts/build-icons.mjs` を書き換えて、この2つから全部出す形にする。

#### なぜこの形で渡すのか

Androidのアイコンは「背景」と「前景」の2枚を重ねる決まりで、端末が円や角丸に
切り抜く。前景を透過で分けてもらえれば、切り抜きに合わせて縮め方を変えられる。
1枚の完成画像だと、切り抜かれる分を見越した余白を絵の中に持たせることになり、
iOSでは余白が大きすぎ、Androidではぎりぎり、という板挟みになる。

### 小さいときに読めるかを必ず確かめる

ホーム画面での実寸は**48〜60px**。1024pxで良く見えても、そこで潰れたら意味がない。

作ったら `assets/icon-preview.html` をブラウザで開いてほしい。書き出した実ファイルを
並べて、**iOSの角丸・Androidの丸マスク・実寸（60/48/32/16px）**で見せるページに
してある（ただし、いまは古いアイコンを見ている。新しいものを見るには、こちらで
組み立て直したあとになる）。

代わりに、**前景を60pxまで縮めた状態を自分で作って見てほしい**。そのうえで:

- 冷蔵庫だと分かるか
- 中身が乗っていることが分かるか（何かは分からなくてよい）
- 線や粒が細かすぎて灰色の塊になっていないか

**細部を減らす判断を優先してほしい。** 1024pxでの描き込みより、60pxでの読みやすさ。

### やらないこと

- `app.js`・`styles.css`・`scripts/` は触らない。組み立てはこちらでやる
- 既存の `assets/icons/*.png` は消さない・上書きしない（新しいものが通るまで残す）
- **commit と push はしない。** ファイルを置いたまま報告してほしい
- 文字・数字・ロゴを入れない

### 報告してほしいこと

- 地の色を変えたなら、その色と理由
- 60pxまで縮めて見た感想（冷蔵庫だと分かるか、中身が乗っていると分かるか）
- 細部を落とした箇所があれば、何を落としたか
- 案が複数できた場合は、**1つに絞って提出**したうえで、落とした案がどんなもので
  なぜ落としたかを1〜2行で書いてほしい
