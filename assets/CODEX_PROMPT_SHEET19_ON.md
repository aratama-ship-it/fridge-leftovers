### 1枚ごとに通してほしい確認

**1. 背景抜けを数えて確かめる**

```bash
node scripts/check-atlas-alpha.mjs 19
```

12マスぶんの「不透明率」と「緑の割合」が出る。判定は次のとおり。

- **不透明率が60%を超えたマスは、背景が抜けていない**（★付きで出る）。
  正常なマスは9〜30%に収まる
- 緑の割合が5%を超えると「?」が付く。**被写体そのものが緑なら問題ない**
  （既存だとパセリが8.7%で正常）。緑でないものに付いたら抜けていない

`背景抜け OK` になるまで次のシートへ進まないでほしい。

**2. 抜けていなかったら、抜き直してシートを作り直す**

```bash
node scripts/key-green.mjs assets/atlas-src/19/xxx.png
```

緑らしさ `g - max(r, b)` で判定して背景を透過にし、境界の緑かぶりを抜く。
**対象ファイルを明示的に渡す作りにしてある。** 被写体が緑の素材（今回だと
パクチー(24)・青のり(21)・バジル類・青じそ系）へ当てると中身まで消えるので、
フォルダ一括処理はできない。抜き直したら `build-atlas.mjs` でそのシートを
作り直し、1をもう一度通す。
