# 食材イラスト 拡張分の生成指示書

作成日: 2026-07-25
宛先: 画像生成の担当（Codex）

このアプリは「冷蔵庫の中に食材イラストが入っているUI」を固有の中心表現にしている。
イラストは装飾ではなく、在庫を思い出すための本体。文字の一覧を読ませず、見た瞬間に中身が分かることを狙う。
そのため**絵柄が既存48種とそろっていることが、単体の完成度より重要**。

## 0. 規模

「スーパーに基本的にあるものを網羅する」方針で、**228品目・19シート**を作る。

| | 数 |
|---|---|
| 今回描く品目 | **228**（うち5件は登録済みでイラストだけ無いもの、223件は新規） |
| シート数 | **19枚**（12品 × 19 = 228、端数なし） |
| 登録食材の増加 | 52 → **275** |
| イラストの総数 | 48 → **276** |

調味料20品目は方針の判断待ちのため別枠（→ 8節）。採用すれば +2シートで計21枚になる。

**着手の順番**。1枚目を確認せずに19枚作ると、寸法や絵柄のずれが出たときのやり直しが228枚分になる。
シート05 →（確認）→ 06〜09 →（確認）→ 残りの順で進めたい。
優先度は、シート05〜09（不足5件・精肉・鮮魚・練り物・日配・葉物）が最も高い。
初回オンボーディングで「今夜の主役」を選ばせる設計のため、肉と魚介が最優先になる。

## 3. 絵柄の指示

水彩・不透明水彩ふうの食材イラスト。図鑑の挿絵に近い。

**守ること**

- 輪郭を黒線で囲まない。色と陰影で形を作る
- 被写体の外側に**ごく細い明るいクリーム色の縁**を付ける（棚の色に乗せても輪郭が読めるため）
- 光は左上からの柔らかい環境光。**地面に落ちる影は描かない**
- 彩度は自然でやや落ち着いた色。蛍光色・過度なツヤは使わない
- 角度は真横〜斜め45度。極端なパースを付けない
- 皿・まな板・小物・背景は描かない。器がないと成立しないものだけ器を描く
  （既存では、ごはんは青い縞の茶碗、ツナは白い小鉢）
- **文字・ラベル・パッケージ・ロゴは描かない**
- 1マス1食材。複数の食材を混ぜない

**避けること**

- 写真、3DCG、フラットなアイコン、ベタ塗り、線画
- 影を落として立体感を強調する表現
- 袋・缶・瓶などの容器（中身だけを描く）

## 4. 品目の選び方

次を見て決めた。**受け入率の統計ではなく、こちら側の判断**である点に注意。

1. 登録済みなのにイラストが無い5件（実データで確認）
2. **カテゴリーの偏り** — 拡張前は野菜19に対し、肉4・魚介5・果物2・乾物2と薄い。
   初回オンボーディングで「今夜の主役」を選ばせる設計にしたため、肉と魚介の薄さが直接効く
   （実データでも麺類・青魚は候補が1〜2件しかなかった）
3. 日本のスーパーの売り場（青果・精肉・鮮魚・日配・練り物・乾物・缶詰・瓶詰・漬物・冷凍・パン・米・粉）を
   二巡し、料理の材料になるものを拾った。菓子・酒・飲料・惣菜・調理済みの冷凍食品は対象外

抜けや不要があれば差し替える。品目の一覧は `scripts/expansion-items.mjs` にあり、
実行するとid重複・単位の妥当性・シートの埋まり・既存idとの衝突を検算できる。

### 描き分けの注意（同じ絵になりやすい組み合わせ）

一覧が275品目に増えると、隣り合う品目が同じ絵に見える危険が出る。次の組み合わせは**意図的に描き分ける**。

- 粉もの：小麦粉・強力粉・片栗粉・天ぷら粉・お好み焼き粉・ホットケーキミックス・白玉粉
  → 粒の粗さと色みで差を付ける（片栗粉は最も白く細かい、天ぷら粉とホットケーキミックスは黄みがかる）
- 豆：大豆・小豆・ひよこ豆・レンズ豆・ミックスビーンズ・枝豆・そら豆・グリーンピース
- ひき肉：ひき肉（合いびき）・豚ひき肉・鶏ひき肉 → 色みで差を付ける（鶏がいちばん白い）
- 白身魚の切り身：たら・かれい・たい・めかじき → 身の厚みと皮の色で差を付ける
- 小魚：しらす・ちりめんじゃこ・煮干し・桜えび → 乾き具合と色で差を付ける
- 緑の葉物：小松菜・チンゲン菜・水菜・春菊・ルッコラ・クレソン・三つ葉・ベビーリーフ
  → 葉の形（切れ込み・丸み・細さ）と株元の作りで差を付ける
- きのこ：しめじ・まいたけ・白まいたけ・えのき・エリンギ・マッシュルーム・なめこ
- 海藻：わかめ・もずく・めかぶ・とろろ昆布・昆布・のり・青のり

## 6. 納品の仕方

- PNG 19枚。ファイル名は各表の見出しのとおり（通し番号 05〜23）
- **まずシート05だけ作って渡してほしい。** こちらでアプリへ組み込み、実機で大きさ・歪み・
  棚に並べたときの見え方を確認してから先へ進みたい。19枚まとめて作ってから
  寸法や絵柄のずれが見つかると、やり直しが228枚分になる
- 透過が保たれているか（背景が白く塗られていないか）を必ず確認する

## 7. 受け入れ基準

1. 1254 × 940 px、PNG、背景が透過
2. 12マスすべてに1品ずつ、マス中心に配置されている
3. 被写体がマス幅の60〜75%に収まり、隣のマスへはみ出していない
4. 既存シートと並べて、塗り・彩度・縁の処理・光の向きが揃って見える
5. 文字・ラベル・容器・皿・落ち影が入っていない（器が必要な数品を除く）
